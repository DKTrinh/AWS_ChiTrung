### Weekly Topic

AWS account setup + Cloud platform overview + Identity and Access Management (IAM)

### Weekly Objectives

* Overview of the internship roadmap and approach core AWS service categories.
* Complete personal environment setup, secure the account, and master IAM authorization principles.

### Work Schedule

| Date | Day | Task Description | Lab / Project |
| :--- | :--- | :--- | :--- |
| 01/06/2026 | Monday | AWS Cloud Practitioner Essentials course. Read all regulations and the 3-month learning roadmap. | [AWS Cloud Practitioner Essentials](https://cloudjourney.awsstudygroup.com/) |
| 02/06/2026 | Tuesday | AWS Free Tier account setup and initial settings. Enable MFA for the root account and install AWS CLI. | [Lab 01 - Create AWS account](https://cloudjourney.awsstudygroup.com/) |
| 03/06/2026 | Wednesday | Identity and Access Management (AWS IAM) module. Analyze the Principle of Least Privilege. | [Module: AWS IAM Fundamentals](https://cloudjourney.awsstudygroup.com/) |
| 04/06/2026 | Thursday | Practice creating Users, Groups, and assigning IAM Policies. Configure IAM Roles and practice Switch Role on the console. | [Lab 02 - Access management with IAM](https://cloudjourney.awsstudygroup.com/) |
| 05/06/2026 | Friday | Summarize Week 1 knowledge. Re-check CLI environment configuration and write the progress report. | Personal Report |

### Expected Outcomes

* Successfully configure AWS CLI and secure the root account with MFA.
* Master academic concepts of cloud computing (Compute, Storage, Networking).
* Understand and apply IAM authorization mechanisms through Users, Groups, Roles, and Policies.
