### Weekly Topic

Cloud network architecture (Amazon VPC) + Virtual server service (Amazon EC2)

### Weekly Objectives

* Analyze and design logical network infrastructure on the AWS platform via VPC.
* Deploy EC2 virtual servers, configure network security, and test connectivity.

### Work Schedule

| Date | Day | Task Description | Lab / Project |
| :--- | :--- | :--- | :--- |
| 08/06/2026 | Monday | Cloud Networking course - Amazon VPC basics. Learn about CIDR blocks and network architecture. | [Module: Amazon VPC](https://cloudjourney.awsstudygroup.com/) |
| 09/06/2026 | Tuesday | Learn about Subnets, Route Tables, and Internet Gateways. Practice dividing Public/Private Subnets. | [Lab 03 - Basic networking with VPC](https://cloudjourney.awsstudygroup.com/) |
| 10/06/2026 | Wednesday | Virtual Server course - Introduction to Amazon EC2. Analyze Instance types and AMIs. | [Module: Amazon EC2](https://cloudjourney.awsstudygroup.com/) |
| 11/06/2026 | Thursday | Practice launching and accessing EC2 Instances. Configure Security Groups to manage traffic (Inbound/Outbound). | [Lab 04 - Launching EC2 Instances](https://cloudjourney.awsstudygroup.com/) |
| 12/06/2026 | Friday | Review VPC, EC2 theory. Attach Elastic IP to the server, test SSH, and finalize week 2 log. | Personal Report |

### Expected Outcomes

* Successfully build an isolated VPC network architecture with clearly routed subnets.
* Launch and manage the lifecycle of an EC2 instance.
* Clearly understand the difference between Security Groups (Instance level) and Network ACLs (Subnet level).
